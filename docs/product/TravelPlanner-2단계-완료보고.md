# TravelPlanner 2단계 완료 보고

- 완료일: 2026-10-20
- 구현 브랜치: `codex/route-aware-planning-v2`
- 생성기: `ROUTE_AWARE_V2`

## 완료 범위

### 장소 데이터

- 위도·경도
- 영업 시작·종료 시각
- 1인 기준 예상 비용
- 권장 체류시간
- 좌표와 영업시간 쌍 입력 검증

### 일정 생성

- 필수 장소와 선호 카테고리 우선순위
- 출발 좌표와 장소 좌표를 이용한 Haversine 직선거리 계산
- 평균 시속 20km 기준 예상 이동시간 계산
- 영업시간 안에서 방문 시작·종료 시각 조정
- 여행 속도와 동행 형태별 하루 방문 수 제한
- 예산을 넘는 선택 장소 제외
- 필수 장소의 예산 초과 허용과 경고 반환
- 배치 불가능한 필수 장소 오류 처리

### 결과 저장

- 일정, 일자, 방문 항목을 한 트랜잭션으로 저장
- 방문 항목별 예상 이동시간 `travelMinutesBefore` 저장
- 방문 항목별 예상 거리 `distanceKmBefore` 저장
- 방문 항목별 예상 비용 `estimatedCost` 저장
- 일정 상세 재조회 시 위 추정값 반환

## 검증 범위

- 전체 자동화 테스트 26개 통과, 실패 0개, 오류 0개
- 조건 입력부터 일정 저장까지의 정상 흐름
- 가까운 장소 우선 배치
- 영업 시작 시각 대기
- 영업시간 밖 필수 장소 거부
- 예산 초과 선택 장소 제외
- 예산 초과 필수 장소 유지
- 생성 후 상세 조회에서 이동·비용 추정값 유지
- 기존 인증·장소·일정 API 회귀 테스트

## 2단계 이후 남은 작업

다음 항목은 현재 2단계 범위 밖이며 외부 공급자나 운영 정책 결정이 필요하다.

1. 실제 도로망과 교통수단별 이동시간 API
2. 외부 장소 데이터 공급자와 적재 정책
3. 요일·공휴일·자정 이후 영업시간 모델
4. LLM 기반 대화형 일정 생성·수정
5. 검색엔진 도입 여부와 제품 검색 품질 기준
6. MySQL 운영 설정과 스키마 마이그레이션 도구
7. WebSocket 공동 편집과 동시성 제어

## 알려진 계산 기준

- 거리: Haversine 직선거리
- 이동시간: 평균 시속 20km, 최소 10분
- 좌표가 없는 장소 사이 이동시간: 30분
- 예상 비용: 장소별 1인 기준 값의 합계
- 영업시간: 모든 날짜에 공통인 하루 시작·종료 시각
